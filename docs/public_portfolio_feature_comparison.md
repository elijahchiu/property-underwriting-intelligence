# Public portfolio feature comparison

This comparison was prepared from the private application's operational README and UI/navigation source and a read-only inspection of its current local Scope workspace at `127.0.0.1:8783`, then checked against the existing public repository and this candidate at `127.0.0.1:8791`. The private project was not changed. No private datasets, application modules, branding assets, or provider code were copied into the candidate. The public screenshots in `docs/` show the candidate; private application views are not packaged with this portfolio because they display private property and provider-budget information.

| Capability | Private Roof4All application | Existing public GitHub edition | Local interactive candidate |
|---|---|---|---|
| Market and neighborhood research | Integrated local and public-source workflow; coverage varies by geography | No interactive market workspace | Three fabricated markets with comparison cards, indicators, and a small visual |
| Property discovery | Address intake plus supported listing/property search | No website or listing discovery | Search and filter five fictional listings |
| Property workspace | Evidence-aware facts, local records, condition, sales, rent, scope, and underwriting sections | Seven-engine synthetic CLI report | Browser workspace with fictional facts, source labels, sale comps, and asking-rent examples |
| Sale and rent analysis | Evidence-admission and comparable review; live provider is optional and guarded | Engine logic exercised only through synthetic fixtures | Three synthetic sales and rental observations per property; median references are shown as simulated |
| Renovation scope | Historical scope corpus, user review, manual inputs, and contractor-review status | Small synthetic priced work subset | Editable itemized scope generated from six synthetic reference projects with disclosed feature weights |
| Data preparation / evaluation | Private source normalization and historical-estimate workflows | Evidence-processing unit tests, no Scope analog holdout | Fictional record validation/integration plus six-record leave-one-project-out method demo; not Roof4All performance |
| Financial underwriting | Integrated evidence and scenario engines; missing evidence can withhold metrics | Synthetic CLI calculations | Browser form for purchase, rent, vacancy, operating costs, debt, NOI, DSCR, cash flow, and cash-on-cash |
| Scenario comparison | Saved versions and property-specific comparisons | Limited command-line scenario example | Live recalculation of assumptions plus four/six-week timing sensitivity |
| Acquisition report | Browser report and print-to-PDF flow with evidence and blockers | Text/JSON CLI output | Print-ready report preview with property, comps, scope, financials, timing, and review items |
| Live data/provider integrations | Local/public connectors and separately guarded optional provider calls | Intentionally absent | Absent; the app makes no external requests |
| Historical/company records | Private evidence and source-document corpus | Excluded | Excluded; all visible fixtures are invented |

## Release boundaries

The interactive candidate is a separately authored public demonstration of the same high-level research sequence. It does not claim feature parity with the private system, use its logo or visual assets, or reuse its internal application code. All values are synthetic.

The existing public seven-engine code was already pushed to GitHub before this candidate. The local candidate does not resolve the ownership or publication-rights status of that existing commit. No new push, release, repository-visibility change, or license selection has been performed.

The app is a local portfolio demonstration, not a hosted service. It binds to loopback only and has no user accounts, saved server-side cases, live feeds, or real-world property resolution.
